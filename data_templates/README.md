# 知识图谱数据模板

本目录的 14 份 Excel 与当前导入器的文件名、列名及数据类型兼容。每个工作簿只有一个数据工作表，第 1 行为表头，后面是可删除或替换的合成示例。所有示例院校、录取、计划、排名、满意度和就业记录均为虚构，不能用于真实报考。

1. 按 [数据模板说明](../docs/数据模板说明.md) 准备所需文件。保留文件名、中文表头和年份格式，代码按文本填写。
2. 将示例行替换为有权使用的真实数据。同一份导入中不要混合真实和合成记录。
3. 把完成的文件放在独立数据目录中，先执行 `python scripts/rebuild_graph.py --validate --data-dir 你的目录`。
4. 在已确认的空 Neo4j 项目库中导入；已有库不要直接运行 `--replace`。

`schema.json` 给出每个文件的列名、类型、最小校验所需表头和合成行，可用于自动核对。表内黄色单元格为示例输入，深色行是导入表头。不要在数据表上方增加标题或说明行，也不要添加说明工作表，否则可能被当作数据读取。

最低完整导入需 7 类基础表和至少 1 份带年份的排名表；本目录提供全部 14 份，以覆盖当前各功能。只有专业分数线而缺少计划时，无法完成已核验的选科推荐。
