# Neo4j 构建数据与模板

当前导入器只适配浙江生源示例。院校所在地可以全国分布，但录取位次不能跨生源省份混用。原始数据不随公开仓库发布，数据提供者应自行确认来源和使用权限。

最低为上表7份基础文件加至少1份排名文件。当前完整模板集14份，排名文件共7份。必需文件可保留合成示例用于演示；真实构建应整体替换为真实且同范围的数据。表头存在并不代表数据质量已核验。

## 表格格式与字段规则

- 每份工作簿第1个非空行为中文表头，不合并表头，数据从下一行开始。不要额外放说明工作表。
- 院校名和专业名用于跨表关联，必须一致。括号中的方向、中外合作或专业组名称应保留，不能随意截断。
- 院校代码、专业代码、目录代码使用文本，保留前导零与T/K后缀；地方招生代码和国家目录代码不是同一字段。
- 最低分、位次、计划人数和投票人数填写数字，不加“分”“名”“人”或千分位文字。位次必须为正整数，缺失留空，不填0。
- 分数线列名采用“2024年最低分”“2024年最低位次”等；计划列采用“2024年计划人数”等。模板覆盖2019–2024分数线和2020–2024计划，未来年份仍需核查应用的数据范围配置。
- 招生计划中的选考科目可填不限、无要求、物、物&化、物或史等。要求集合被考生选科包含时符合；匹配计划中的空白表示不限，缺少整条计划则待核实。原表要求目前是行级字段，跨年度政策变化需拆分数据结构后再支持。
- 计划数0是有效值；录取和计划某年没有数据时留空，不复制其他年份。
- 就业比例原文采用“浙江:70%;上海:30%”形式，当前只提取带显式百分号的条目；未提供的统计年份不推测。
- 学科评估“一级学科”可为“0812 计算机科学与技术”，“院校代码及名称”为5位院校代码、空格与院校名。
- 排名表支持原始7种列名变体，年份从文件名提取。2022模板工作表为“总榜”，避免被误认为分榜。
- 重复且冲突的同校同专业同年分数线保留来源并排除出推荐；多个计划无法唯一对应时不任选、不自动求和。

## 构建步骤

```powershell
python scripts/prepare_demo_data.py
python scripts/rebuild_graph.py --validate --data-dir data/demo
python scripts/rebuild_graph.py --sample 2 --data-dir data/demo
# 已在.env中配置独立空Neo4j数据库后：
python scripts/rebuild_graph.py --data-dir data/demo
```

最后一步会写入配置的 Neo4j。只有确实需要覆盖且已备份目标库时，才加 `--replace`，该选项会删除目标库的图谱、旧索引和约束。`--validate` 不连接数据库，只检查必需文件和表头；构建还会检查事实、唯一关系及来源。

现有数据集ID固定为zhejiang-admissions-2019-2024-v2；增加年份、生源省份、批次或逐年选科结构时，需要同步数据范围、筛选、上下文和回归测试。不要仅改Excel就宣称已支持全国各省或最新年份。
