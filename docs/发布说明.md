# 公开发布说明

项目名称：VRS 志愿推荐系统。仓库使用 ASCII 名称 `VRS-Zhiyuan-Recommendation`，中文名称保留在说明中。

## 发布内容

代码、通用配置样例、设计文档、测试和导入工具；14 份与导入器兼容的 Excel 合成示例模板及字段契约。

## 留在本机的内容

真实原始 Excel、考生成绩与策略、SQLite 数据库、Neo4j dump、API 密钥、数据库密码、机器路径配置、详细联测输出和个人交接记录。这些内容不随公开仓库分发。

凭据可由环境变量、被忽略的项目 `.env` 或仓库外的用户私有文件加载。代码和配置样例没有内置数据库密码，模型密钥为空。不要将本机私有配置复制到仓库。

本次在独立发布目录以干净初始历史发布，旧项目中曾含凭据的历史不进入新仓库。原开发目录的 Git 历史保留，旧远程仓库没有被覆盖。请在干净发布目录继续公开版本的开发，不要向新仓库推送原目录的旧历史或使用 mirror。已出现在旧历史或其他地方的密钥，需要由持有人在服务商平台撤销或轮换。

## 验证方式

```powershell
python -m unittest discover -s tests -v
node tests/frontend_regression.cjs
python scripts/rebuild_graph.py --validate --data-dir data_templates
python scripts/check_secrets.py --history
```

模板生成后已核对列名、数据值、文本代码和导入预检，并检查所有模板的可读性。真实完整资料联测与合成演示的数量预期不同，不应混用。

仓库公开与应用服务公开是两回事。当前仍为本地演示鉴权；面向多人部署前，需要另行完成正式账户、权限与数据隔离。
